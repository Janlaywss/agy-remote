# 开发记录

日期采用北京时间。本记录按功能演进整理；当前部署以仓库中的源码和配置为准。

## 2026-11-17 · 建立 Mac 执行通道

Mac 与 VPS 已加入同一 Tailscale 网络，实测能通过内网地址 SSH 登录。为让服务器上的 agy 直接操作 Mac 文件和 zsh，Mac 通过 SSH 将本地 Unix socket 反向转发到 VPS，VPS 将它注册为 `mac/mac_shell`。全局规则将普通文件和命令请求指向 Mac。通过该通道验证了读写临时文件以及运行 `uname -s`、`pwd`。

初版 Mac 工作目录固定为 `~/Codex`。随后加入本地启动器 `agy-mac`，每次启动用 `AGY_MAC_CWD` 传递终端当前目录。分别从两个含中文和空格的目录同时启动会话，两次 `pwd` 均返回各自目录。

Mac 空闲睡眠曾使长连接中断。唤醒后 SSH 隧道恢复，但旧 MCP 会话继续使用断开的连接。VPS 代理改为本地响应初始化和工具发现，执行时为每次调用建立新连接；Mac 用 launchd 维持隧道。启动器通过 `caffeinate -i` 在 SSH 会话期间防止空闲睡眠，实测进程退出后释放电源断言。

## 2026-11-23 · 长命令转后台

长时间运行的数据生成任务超过 agy 的工具调用等待时间。客户端超时后脚本仍在 Mac 上执行，同一代理仍在等待结果。加入 `agy-mac-job`：短命令同步返回，超过 5 秒的任务返回编号，输出和退出状态写入 Mac 用户日志目录。用一次有意返回退出码 7 的长命令验证，同会话在任务执行期间可以运行 `pwd`、查询日志，任务结束后能读到最终输出和退出码。

## 2026-11-24 · 在远程 TUI 粘贴 Mac 图片

普通 SSH 传递终端输入时，服务器上的 CLI 读不到 Mac 图形剪贴板。Mac 侧新增 Swift/AppKit PNG 读取程序和按需启动的剪贴板 LaunchAgent；启动器为每次会话分配单独的反向转发 socket。VPS 侧的轻量 `xclip` 适配器把 PNG 交给 agy。使用命名测试剪贴板中的图片按 Control + V，远端 TUI 显示已附加一个 PNG。

## 2026-11-25 · 修复代理退出后整场会话不可用

服务器日志记录了 10:56 的 `exit status 1`。原始日志未保留具体请求。测试发现遗漏 `command` 或传入 `cwd: null` 可触发同类崩溃。修复后的代理对无效参数返回 JSON-RPC 错误；同一进程连续处理两条无效请求后，又成功执行了 `pwd` 和目录可读性检查。

## 2026-11-25 · 建立源码仓库

首次将已部署的 Mac 启动器、任务管理器、服务、LaunchAgent 和当前 VPS 代理、工具定义、规则、剪贴板适配器纳入同一个本地 Git 仓库。剪贴板读取程序从原构建目录取回 Swift 源码。此次新增两端安装脚本、部署与验证说明以及维护指南。

归档校验覆盖 7 个已部署的 Mac 脚本和 plist，以及 5 个 VPS 文件，逐项内容一致。使用仓库中的 Swift 源码重新编译后，从命名测试剪贴板读到了有效的 32 × 32 PNG。经过实际 VPS 代理连续发送初始化、工具发现、非法参数和有效命令，请求均返回预期结果，最后一条命令在 Mac 上读到了本仓库。安装脚本通过 shell 语法检查；此次验证使用现有部署。


## 2026-11-26 · 构建时注入部署参数

连接地址、SSH 用户、密钥路径和 VPS 主目录改为由环境变量提供。Mac 构建生成私有连接配置与 launchd 配置，并编译剪贴板读取程序。私钥由 OpenSSH 根据路径读取。VPS 安装时通过当前用户的主目录注册 MCP。
