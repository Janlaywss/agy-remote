# 部署与验证

Mac 需要 Python 3、zsh、OpenSSH、Swift 编译器和 AppKit。VPS 需要 Python 3、允许反向 Unix socket 转发的 SSH 服务，以及已登录的 `~/.local/bin/agy`。两端须能通过 SSH 互通，使用 Tailscale 时可填服务器的内网地址或可解析的名称。

## 在 Mac 准备构建环境

从仓库根目录复制环境模板并填入本机值。模板是 shell 文件，有空格的值请保留引号。

```sh
(umask 077 && cp -n .env.example .env.local)
"${EDITOR:-vi}" .env.local
set -a
. ./.env.local
set +a
```

| 变量 | 值 |
| --- | --- |
| `AGY_SSH_HOST` | Mac 可访问的 VPS 主机名、SSH 别名或 IP |
| `AGY_SSH_USER` | 运行 agy 的 VPS 登录账号 |
| `AGY_SSH_KEY_PATH` | Mac 上 SSH 私钥文件的绝对路径，仅填写路径 |
| `AGY_VPS_HOME` | 该 SSH 账号在 VPS 上的绝对主目录，供两端定位反向转发 socket |

构建在本地生成 `build/mac/connection.json`、三份带绝对路径的 plist 和编译好的 `read-png`。前两个服务由执行构建的 Python 解释器运行，剪贴板服务由编译结果直接运行。SSH 私钥的读取由 OpenSSH 完成。Git 忽略 `.env.local` 和整个 `build/`，生成目录属于本机私有部署文件。

```sh
python3 mac/build.py
plutil -lint build/mac/*.plist
```

## 安装 VPS 端

在 VPS 的仓库根目录以运行 agy 的账号执行 `sh vps/install.sh`。如果从 Mac 传送源码，可在上述环境中运行：

```sh
target="$AGY_SSH_USER@$AGY_SSH_HOST"
ssh -i "$AGY_SSH_KEY_PATH" "$target" 'mkdir -p ~/src/agy-remote'
scp -r -i "$AGY_SSH_KEY_PATH" ./vps "$target:src/agy-remote/"
ssh -i "$AGY_SSH_KEY_PATH" "$target" 'sh ~/src/agy-remote/vps/install.sh && ~/.local/bin/agy mcp list'
```

`mcp list` 中应出现已启用的 `mac` stdio 服务。安装脚本将代理、缓存的工具定义和剪贴板适配器放进 `~/.local/state/agy-mac/`，安装全局规则，再用 `agy mcp add` 注册当前用户的代理绝对路径。首次 SSH 登录时请核实服务器指纹。

## 安装 Mac 端

从已登录图形桌面的 Mac 终端执行。脚本使用已导出的变量重新构建并安装配置，同时重新加载三个用户服务。更新安装会短暂中断正在进行的工具调用。

```sh
sh mac/install.sh
```

命令安装在 `~/.local/bin`，运行文件和权限为 `0600` 的连接配置安装在 `~/.local/share/agy-mac/`。launchd 从 `~/Library/LaunchAgents/` 加载服务。安装后，每次运行 `agy-mac` 会读取已安装的配置。修改连接参数时，更新本机环境并重新运行安装脚本。

## 验证

1. 在 Mac 运行 `agy-mac --help`，接着在项目目录运行 `agy-mac` 并要求执行 `pwd`。输出应为该 Mac 目录。
2. 在 TUI 中要求执行 `echo start; sleep 15; echo done; exit 7`。约五秒后应得到任务编号。期间可执行其他命令，结束后用 `agy-mac-job status <任务编号>` 查看最终输出和退出码 7。
3. 复制一张测试图片，在 TUI 按 Control + V，出现 `media attached` 即表示附件已读入。
4. 在 VPS 终端执行下面两条 JSON-RPC 请求。第一条应返回参数错误 `-32602`，第二条应返回 Mac 用户的主目录和退出码 0，说明同一个代理进程继续工作。

```sh
~/.local/state/agy-mac/mac-cwd-proxy <<'JSON'
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"mac_shell","arguments":{}}}
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"mac_shell","arguments":{"cwd":"~","command":"pwd"}}}
JSON
```

## 定位故障

| 现象 | 检查方法 |
| --- | --- |
| VPS 登录失败 | 确认主机可达，并用环境中配置的身份文件单独测试 SSH 登录。使用 Tailscale 时检查两端的 `tailscale status`。 |
| TUI 能启动，但无法执行 Mac 命令 | 在 Mac 查看 `launchctl print gui/$(id -u)/local.agy-mac.tools` 和 `launchctl print gui/$(id -u)/local.agy-mac.tunnel`；日志是 `~/.local/share/agy-mac/tools.log` 和 `tunnel.log`。 |
| 调用超时，结果不明 | 用 `agy-mac-job list` 找到任务。完整输出在 `~/Library/Logs/agy-mac/jobs/<任务编号>/output`。核对任务状态与产物后再决定是否重试。 |
| 图片不能粘贴 | 通过 `agy-mac` 新开会话；在 Mac 查看 `launchctl print gui/$(id -u)/local.agy-mac.clipboard`。每次会话通过自己的转发 socket 读取剪贴板图片。 |
